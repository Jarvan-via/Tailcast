# Autopricy SEO Growth Knowledge Base

This directory is the durable operating record for Autopricy organic acquisition. It exists to prevent repeated research, unsupported product claims, duplicate backlink submissions, and page creation without a measurable search intent.

## Goal

Acquire real cross-border marketplace sellers through non-brand Google search. Page count, article count, backlink count, DA, and DR are supporting observations—not success metrics.

Primary business metrics:

1. Google Search Console impressions and clicks for non-brand queries.
2. Target-keyword position and landing-page organic sessions.
3. Organic registration, activated trial, first connected shop, first pricing rule, and paid conversion.
4. Organic acquisition by marketplace, not only site-wide totals.

## Product boundary

Autopricy is marketplace repricing software with adjacent seller workflows: competitive-offer monitoring, price boundaries, product/Offer collection, listing/follow-selling where verified, and multi-shop operations. It is not an ERP and must not be positioned as order, warehouse, procurement, finance, logistics, or after-sales software.

Every public capability claim must be supported by current code plus, where the claim says “live” or “available,” production or platform evidence. See [product-capabilities.md](./product-capabilities.md).

## Phase gates

Backlink work starts only after all of the following are true:

- the approved priority landing pages are live;
- page claims have passed the product-capability gate;
- canonical, sitemap, internal links, status codes, and indexability pass;
- the pages are readable without client-side JavaScript;
- Search Console verification and sitemap submission are confirmed;
- the first page set has been manually reviewed for usefulness and language quality.

Directory submissions use SPD V2 Quality only, in batches of at most 10 candidates. No bulk traversal, mass registration, CAPTCHA bypass, paid-link purchase, forced reciprocal link, or exact-match anchor campaign is allowed.

## Working rule for future sessions

Read this file, `progress.md`, `product-capabilities.md`, and the relevant research file before changing the website or researching backlinks. Update the record in the same change set as the work. Never convert a code path, enum, or old legal-page mention into a live support claim.
